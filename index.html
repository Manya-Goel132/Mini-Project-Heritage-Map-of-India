📖 Problem & Solution

Traditional methods relying on static textbooks and flat diagrams treat cultural history as fixed data points, failing to evoke the living, spatial reality of Indian heritage.

This dynamic web cartography platform bridges ancient traditions with modern front-end engineering. Users interact with a clickable vector map of India, exploring GI-tagged crafts, folk dances, and listening to authentic 5-second traditional soundscapes for each region.

⚡ Exact Technology Stack

HTML5 / CSS3
Responsive UI, glassmorphism, tailored Indian heritage aesthetics.
Vanilla JavaScript
Lightweight client-side interactivity without heavy dependencies.
Leaflet.js
Interactive mapping engine rendering GeoJSON vector boundaries.
HTML5 Audio API
Native audio engine dynamically streaming 5-second folk soundscapes.

🗄️ System Architecture

• data/india_states.geojson: Renders precise state vector polygons.
• const stateData = [...]: Houses rich cultural datasets per state (GI tags, folk arts, soundscape paths).
